# Portal de Viagens | Ecovias Araguaia

## Preparação da infraestrutura

Projeto Firebase informado: `ecovias-araguaia-viagens`.

**Não está publicado para uso real.** A versão atual do portal ainda usa `localStorage` e login demonstrativo. Antes de publicar, é necessário conectar Firebase Authentication e Cloud Firestore, definir regras de acesso, e testar a leitura entre dispositivos.

O código-fonte e a configuração de Hosting serão preparados neste repositório. Não envie credenciais para o GitHub.
